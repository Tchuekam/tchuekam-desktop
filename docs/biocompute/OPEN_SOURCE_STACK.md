## Provenance & Integration Directives

1. **No Proprietary Code Re-implementation:** Standard scientific packages (`brian2`, `reservoirpy`, `neo`, `elephant`, `snntorch`, `scikit-learn`, `torch`) must be imported as standard Python dependencies via `pyproject.toml` or `uv`.
2. **Attribution Requirement:** All scientific outputs generated by the platform record the versions of underlying scientific libraries in the `provenance` block of the experiment manifest.
